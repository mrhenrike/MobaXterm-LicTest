# MobaXterm Labs (pt-BR)

Gerador de ficheiro **CustomProKey** para **testes de licenciamento** do MobaXterm.

**English:** [README.md](README.md) · [CONTRIBUTING.md](CONTRIBUTING.md) · [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

## Uso

```
mobaxterm-testprokey.py <UserName> <Version>
```

Exemplo: `mobaxterm-testprokey.py "mrhenrike" 22.1` — gera `Custom.mxtpro` na pasta atual; copie para o diretório de instalação do MobaXterm.
